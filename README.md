# WhatsApp AI Smart Recall

An AI-powered smart recall system for WhatsApp chats that helps users search, retrieve, summarize, and manage conversations intelligently using Natural Language Processing and AI techniques.

---

## 🚀 Features

* 🔍 Smart message search
* 🤖 AI-powered conversation recall
* 🧠 Context understanding
* 📄 Chat summarization
* ⏱️ Quick retrieval of old messages
* 📱 User-friendly interface
* 🔐 Secure data handling
* ☁️ MongoDB database integration

---

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/whatsapp-ai-smart-recall.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd whatsapp-ai-smart-recall
```

### 3️⃣ Install Dependencies

```bash
npm install
```

For server dependencies:

```bash
cd server
npm install
```

---

## 🔑 Environment Variables

Create a `.env` file in the server folder and add:

```env
MONGO_URI=your_mongodb_connection
PORT=5000
HUGGINGFACE_API_KEY=your_api_key
```

---

## ▶️ Running the Project

### Start Backend Server

```bash
cd server
npm start
```

### Start Frontend

Open the frontend files in browser or run with Live Server.
